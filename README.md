# Micro-API de Gerenciamento de Tarefas

Projeto desenvolvido como atividade prática da pós-graduação em Engenharia de Software com Inteligência Artificial Generativa.

## Objetivo

Desenvolver uma API RESTful para gerenciamento de tarefas, utilizando Python, FastAPI e SQLite, com apoio de ferramentas de Inteligência Artificial Generativa durante o desenvolvimento.

## Tecnologias previstas

- Python 3.10
- FastAPI
- SQLite
- SQLAlchemy
- Pydantic
- Pytest
- Git e GitHub
- IntelliJ IDEA e Codex

## Funcionalidades previstas

- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas por status
- Sugerir prioridades utilizando IA, com fallback local

## Arquitetura

A aplicação será organizada em camadas:

API → Service → Repository → SQLite
